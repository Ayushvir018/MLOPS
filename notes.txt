==================================
Phase-2: Virtualization with Docker
==================================

Why we need Docker ?
- Imagine you are running your code on your laptop with a different programming version and another user is working on a different version...

Reason of failures:
- Using different programming version
- Using different version of libraries like scikit-learn, FastAPI
- Missing Python packages
- Different OS dependencies

Docker helps package your application code, runtime, dependencies and startup instructions into a standardized image

4 major requirements:
- Dockerfile - Set of instructions for packaging ML application
- Image - Packaged reusable application artifact
- Container - A running instance of the image
- Port Mapping - Makes the API inside the container accessible from your system

Docker commands:
docker Ps
Check running container
docker ps -a
check all active/non active container

docker build -t mlops-iris-image-command .
-t =tag name= name of the image


docker run -d -p 8000:8000 --name mlops-cs-container mlops-iris-image-cs
